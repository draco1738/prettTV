prettTV — native Android TV launcher

All three layouts are implemented. C Balanced is the owner's selected TV Home. All layouts use persistent opaque top navigation; the current README images are actual 0.4.0 TV screenshots. Version 0.4.1 improves Home return and TCL shortcuts, adds Bluetooth on/off with state checks and double speaker-Mute through the existing authorized helper, repairs bounded discovery lookup/filter dead ends, and hardens app-removal/update recovery and Updates focus without redesigning Home. Physical shortcut and device-test limits remain in docs/validation.md.

The repository is public at https://github.com/draco1738/prettTV. Releases include the pinned RBTV companion bundle; see docs/validation.md for versioned observations and remaining limits. Historical Git commits remain intact. Preserve Rivi's MIT attribution and history. Do not publish signing keys, account data, ADB identities, private preference backups, SDK/Gradle caches, or proprietary decompiled source.
